# 翻譯任務：顧客評論 → 香港繁體中文（廣東話書面語）

每個輸入檔係 JSON array：`[{"id": "...", "text": "原文"}]`（原文可能係日文、英文、韓文、簡體／繁體中文等）。

規矩：
1. 忠實翻譯：唔准加嘢、唔准刪嘢、唔准潤飾成廣告語。原文冇講嘅功效、感受一律唔好加。
2. 用香港廣東話書面語（例：「用起嚟好方便」「色號唔偏紅」「搽完」「好啱」），繁體字。
3. emoji、色號名／編號、產品名照原文保留（色號名可以喺後面加中文意思，例：「06 フラワーコーラル（花朵珊瑚色）」）。
4. 換行用 \n 保留原文段落。
5. 原文已經係中文：簡體轉繁體、意思唔改，lang 寫「中文」。
6. lang：原文語言，用「日文」「英文」「韓文」「中文」「西班牙文」等。

輸出：JSON array，同輸入一樣次序，全部 id 都要有：
`[{"id": "...", "zh": "譯文", "lang": "日文"}]`
寫去 `work/tr-out/<同一個檔名>`（合法 JSON，唔好加 markdown）。唔好改其他檔。
